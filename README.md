# Introduction to Machine Learning: Build an End-to-End Classifier

A beginner project in Python that walks the entire machine-learning workflow end to end. You load a real dataset with Pandas, explore and visualize it with Matplotlib, clean and scale the features, split into train and test sets the honest way, fit a scikit-learn classifier, evaluate it with accuracy, precision, recall, and a confusion matrix, improve it with feature scaling and a little hyperparameter tuning, then persist the trained model and wrap it in a tiny command-line predictor. The focus is the workflow and the why behind each step — not deployment — so you finish able to take any tabular dataset from CSV to a model you can actually use.

## Stack
- Python
- NumPy
- Pandas
- Matplotlib
- scikit-learn
